Acerca de

Cómo funciona este asistente.

Este proyecto fue pensado para quienes necesitan ayuda en el ámbito laboral, educativo y personal, y para estudiantes, con el propósito de nutrir sus conocimientos y mejorar su análisis de información.

PDF Questioner responde solo con lo que dicen tus documentos y siempre te indica de qué archivo y página sacó la información.

  1. Sube un PDF con texto (los escaneados como imagen no funcionan).
  2. Espera el mensaje verde de que quedó listo.
  3. Escribe tu pregunta y presiona Enter.
  4. Usa «Nueva consulta» para empezar de cero.
Requisitos y privacidad

Funciona con Ollama (modelo llama3.2), que se ejecuta en tu propio equipo. Por eso tus documentos no salen de tu computadora. Se recomienda tener 8 GB de RAM o más; con menos memoria puede responder muy lento.
